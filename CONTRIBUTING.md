# Contributing

PocoLobby is maintained by a single author. Pull requests from outside contributors are not accepted. Ideas are welcome as feature requests through GitHub issues.

## Bug reports

[Open an issue](https://github.com/johansan/pocolobby/issues/new) with the PocoLobby version (`pocolobby check-config` reports it for an agent's MCP file, and an agent's `get_context` reports the broker's), the Claude Code version, your operating system, where the broker runs, the steps that reproduce it, and what you expected. Leave out keys, tokens and credential files.

## Feature requests

[Open an issue](https://github.com/johansan/pocolobby/issues/new) that describes what you were doing, what got in the way, and what you would like to happen.

## Security issues

Security issues follow a separate process. See [SECURITY.md](SECURITY.md).

## Pull requests

Pull requests are not accepted. They are closed automatically without review.

PocoLobby is maintained by a single developer. Bug reports and feature requests through GitHub issues are the supported way to influence the project.
